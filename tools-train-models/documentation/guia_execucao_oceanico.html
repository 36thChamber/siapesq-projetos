Guia de Execução — Pipeline Oceânico (SDM marinho)

Um comando roda tudo: ocorrências → pseudo-ausências no oceano → variáveis do mar (CMEMS) → controle de qualidade → Random Forest em Python e/ou R → mapa anual de validação. Espécie de referência: Pomatomus saltatrix.

1Preparação (uma vez só)

  • Abra o terminal na raiz do projeto (C:\Users\user\Documents\Projetos\tools-train-models). O projeto assume que tudo roda a partir da raiz.
  • Use o Python do projeto: sempre .venv\Scripts\python.exe (não o Python global).
  • Batimetria: confira que dados_entrada\ocean_depth.nc existe (já vem no projeto; um GEBCO pode ser usado no lugar via --batimetria).
  • Credenciais do Copernicus Marine (CMEMS) no arquivo .env — necessárias para baixar temperatura/salinidade/clorofila. Nunca enviar o .env para o git.
  • R (opcional): só para --engine r ou ambos. Precisa do Rscript.exe (achado sozinho em C:\Program Files\R\R-*) com o pacote randomForest.

2Ver o plano antes de rodar (custo zero)

O --dry_run imprime cada comando que seria executado e os caminhos dos arquivos, sem baixar nem calcular nada. Use sempre antes de uma rodada de verdade.

.venv\Scripts\python.exe run_pipeline_ocean.py --dry_run

3O comando único

.venv\Scripts\python.exe run_pipeline_ocean.py --especie "Pomatomus saltatrix" --seed 42

Por padrão ele roda as 6 etapas com --engine ambos (Python + R + comparação) no domínio do Atlântico Sul, e grava tudo em 07 Executado por espécie\Pomatomus_saltatrix\.

Escolhendo o motor da modelagem (--engine)

:: só Python (scikit-learn)
.venv\Scripts\python.exe run_pipeline_ocean.py --engine python

:: só R (randomForest)
.venv\Scripts\python.exe run_pipeline_ocean.py --engine r

:: os dois + comparação Python x R ao final (padrão)
.venv\Scripts\python.exe run_pipeline_ocean.py --engine ambos
Como o R e o Python conversam Para a comparação ser justa, o R treina nas mesmas linhas que o Python (arquivo *_dados_split.csv) e prediz nas mesmas células do mapa (arquivo *_gridX.csv). Esses dois arquivos são criados pelo caminho Python. Se você pedir --engine r e eles ainda não existirem, o orquestrador roda o passo Python correspondente automaticamente e avisa na tela — é esperado, não é erro.

Outros exemplos úteis

:: retomar da modelagem (dados já capturados), só R
.venv\Scripts\python.exe run_pipeline_ocean.py --engine r --start modelo

:: parar no controle de qualidade (sem treinar)
.venv\Scripts\python.exe run_pipeline_ocean.py --stop qc

:: domínio global (quando o Atlântico Sul rende poucas presenças)
.venv\Scripts\python.exe run_pipeline_ocean.py --bbox -180 -90 180 90

:: injetar um CSV de ocorrências pronto (pula o download)
.venv\Scripts\python.exe run_pipeline_ocean.py --occ_csv caminho\dados.csv

4Etapas e saídas

#EtapaO que fazSaída principal
1occ Baixa e limpa ocorrências de 7 fontes marinhas (config_marinho.yaml) Occurrence_<Especie>_DD_MM_AA.csv
2pseudo Tira pontos em terra (batimetria) e sorteia pseudo-ausências só no oceano, na faixa de profundidade das presenças Pseudoabsence_*.csv + Map_*.png
3captura Anexa sst, sss, chl (+ chl_log10) do dia de cada registro (CMEMS) e a profundidade <Especie>_variables_marinho_<data>\Variables_*.csv
4qc Portão de qualidade: APTO/REVISAR seguem; NAO_APTO interrompe o pipeline QCVeredito_*.json/.txt
5modelo Random Forest Python e/ou R (mesmo split; métricas AUC/TSS/MCC…) modelo_rf_marinho\rf_*_marinho.joblib / _R.rds + *_eval.json
6predicao Mapa anual de validação (média 2015-2024 do oceano); com ambos, fecha com a comparação Python×R pred_*_adequabilidade.tif/.png + comparacao_py_r_*.txt/.json + comparacao_mapas_*.png

Tudo fica em 07 Executado por espécie\<Genero_especie>\, na convenção de nomes do projeto (naming.py). As etapas 3 e 6 têm cache em dados_saida\ e continuam de onde pararam se a rodada cair.

5Solução de problemas

"[GATE] QC marinho: veredito NAO_APTO — pipeline interrompido" Não é defeito: o portão de qualidade barrou o conjunto de dados (menos de 100 presenças, menos de 100 casos completos ou variável degenerada). Leia o motivo em QCVeredito_*.txt. Saída comum: alargar o domínio com --bbox -180 -90 180 90 e rodar de novo desde o início.
"Rscript não encontrado" Instale o R (com o pacote randomForest) ou informe o caminho: --rscript "C:\Program Files\R\R-4.x.x\bin\Rscript.exe". Se não precisa do R, use --engine python.
Falha de download do CMEMS (etapas 3 e 6) Confira as credenciais no .env e a internet, e rode o mesmo comando de novo — o cache faz a captura retomar do ponto em que parou (dados_saida\cmarine\ e dados_saida\pred_marinho_cache\).
Aviso "apenas N presenças (< 100)" após a etapa 1 O pipeline continua, mas o QC (etapa 4) vai bloquear. Antecipe-se: rode com --bbox maior ou confira a grafia do nome científico.
Quero repetir só uma parte --start modelo reusa o Variables_*.csv já capturado e treina de novo; --start predicao refaz só o mapa; --stop captura para no CSV de treino. O --dry_run mostra o que cada combinação faria.
Reprodutibilidade Repetir o comando com o mesmo --seed gera as mesmas pseudo-ausências e o mesmo split de treino/teste.
